# Пошаговый запуск Журнала IB на своём сервере

Инструкция рассчитана на человека без опыта администрирования. Займёт около 1–2 часов, плюс время на подтверждение покупки сервера и домена.
Если что-то пошло не так, скопируйте текст ошибки и пришлите его разработчику (или Claude).

---

## Шаг 1. Арендовать сервер (VPS) в Казахстане

Данные учеников по закону РК должны храниться в Казахстане, поэтому сервер нужен у казахстанского провайдера.

1. Откройте сайт провайдера, например:
   - **https://www.ps.kz** — раздел «Облачные серверы» / «VPS»;
   - **https://hoster.kz** — раздел «VPS / VDS».
2. Зарегистрируйтесь (как организация, если платит школа).
3. Выберите конфигурацию:
   - **2 vCPU, 4 ГБ RAM, 40 ГБ SSD** (или больше);
   - операционная система **Ubuntu 24.04**.
4. Оплатите. В письме или в личном кабинете появятся:
   - **IP-адрес** сервера (например `185.22.xx.xx`);
   - **логин** (обычно `root`) и **пароль**.

Запишите IP, логин и пароль — они понадобятся дальше.

## Шаг 2. Домен (адрес сайта)

Нужен адрес вида `journal.ваш-лицей.kz`.

**Вариант А — у школы уже есть сайт** (например `ваш-лицей.kz`). Попросите того, кто управляет сайтом школы, создать **A-запись**:

| Тип | Имя | Значение |
|---|---|---|
| A | `journal` | IP-адрес сервера из шага 1 |

**Вариант Б — домена нет.** Купите его там же, где сервер (на ps.kz или hoster.kz есть «Регистрация доменов»). В панели управления доменом («DNS-записи») добавьте A-запись: имя `journal` (или `@` для самого домена), значение — IP сервера.

Изменения DNS начинают работать через 15 минут — несколько часов. Проверить можно на **https://dnschecker.org**: введите `journal.ваш-лицей.kz`, там должен появиться IP вашего сервера.

## Шаг 3. Подключиться к серверу

- **Windows:** нажмите «Пуск», наберите `PowerShell` и откройте его.
- **Mac:** откройте программу «Терминал».

Введите (вместо `IP` — адрес сервера):

```bash
ssh root@IP
```

На вопрос `Are you sure you want to continue connecting` напишите `yes` и нажмите Enter. Затем введите пароль из шага 1. Символы при вводе не отображаются, это нормально.

Если видите строку вида `root@имя-сервера:~#` — вы на сервере. Все команды дальше вводятся в это окно: скопировать, вставить (правой кнопкой мыши), нажать Enter.

## Шаг 4. Подготовить сервер

Обновить систему и установить Docker (займёт 2–5 минут):

```bash
apt update && apt -y upgrade
```

```bash
apt -y install docker.io docker-compose-v2 git ufw unattended-upgrades
```

Включить защиту портов (разрешить только SSH и сайт). На вопрос ответьте `y`:

```bash
ufw allow OpenSSH && ufw allow 80/tcp && ufw allow 443/tcp && ufw enable
```

## Шаг 5. Скачать программу

```bash
git clone -b claude/production-db-security https://github.com/festeast/toddle-.git journal
```

```bash
cd journal
```

> Когда изменения будут влиты в основную ветку, часть `-b claude/production-db-security` можно убрать.

## Шаг 6. Настройки

Создайте файл настроек:

```bash
cp .env.production.example .env.production && chmod 600 .env.production
```

Сгенерируйте пароль для базы данных и **скопируйте** выведенную строку:

```bash
openssl rand -hex 32
```

Откройте файл настроек в редакторе:

```bash
nano .env.production
```

Измените три строки (стрелками перемещаться, стирать — Backspace):

```
DOMAIN=journal.ваш-лицей.kz
APP_URL=https://journal.ваш-лицей.kz
POSTGRES_PASSWORD=строка-которую-вы-скопировали
```

Остальное пока не трогайте (вход через Google настраивается в шаге 11).
Сохранить: **Ctrl+O**, затем **Enter**. Выйти: **Ctrl+X**.

## Шаг 7. Собрать и запустить

Короткое имя для длинной команды (вводить после каждого нового подключения к серверу, находясь в папке `journal`):

```bash
C="docker compose -f docker-compose.prod.yml --env-file .env.production"
```

Сборка (5–15 минут, много текста — это нормально):

```bash
$C build
```

Запустить базу данных:

```bash
$C up -d db
```

Создать таблицы в базе:

```bash
$C --profile tools run --rm tools
```

В конце должно быть `All migrations have been successfully applied`.

## Шаг 8. Создать школу и администратора

Подставьте свои данные: название школы, короткий код латиницей, email, имя и фамилию администратора, адрес сайта.

```bash
$C --profile tools run --rm tools node_modules/tsx/dist/cli.mjs scripts/setup-school.ts --name "Лицей №1" --code LYC1 --admin-email admin@ваш-лицей.kz --admin-first Гульнара --admin-last Сапарова --app-url https://journal.ваш-лицей.kz
```

Скрипт выведет ссылку вида `https://journal.ваш-лицей.kz/invite/...`. **Скопируйте её**: она одноразовая и действует 72 часа.

Запустить сайт:

```bash
$C up -d
```

## Шаг 9. Первый вход

1. Откройте в браузере ссылку из шага 8. Если появилась ошибка сертификата, подождите 1–2 минуты (сайт получает HTTPS-сертификат) и обновите страницу.
2. Придумайте пароль: **не короче 10 символов**, лучше фраза из нескольких слов. Нажмите «Сохранить и войти».
3. Вы в админке. Дальше вход — по адресу `https://journal.ваш-лицей.kz`, email и паролю.

Проверка: адрес `https://journal.ваш-лицей.kz/api/health` должен показывать `{"ok":true}`.

## Шаг 10. Загрузить учеников, родителей, учителей и курсы

**10.1. Заполнить таблицы.**
1. Откройте шаблоны на GitHub, нажмите **Download raw file** (значок загрузки справа):
   - https://github.com/festeast/toddle-/blob/claude/production-db-security/deploy/templates/people.csv — люди;
   - https://github.com/festeast/toddle-/blob/claude/production-db-security/deploy/templates/courses.csv — курсы.
2. Откройте файлы в Excel или Google Таблицах, удалите примеры и заполните своими данными:
   - **people.csv:**
     - `role` — `admin`, `deputy` (завуч), `coordinator_myp`, `coordinator_dp`, `advisor` (классный руководитель; в `class` — его класс), `teacher`, `student`, `parent`;
     - для ученика обязателен `class` (7A, 10B, DP1);
     - для родителя — `child_email`: email ребёнка, нескольких детей разделите знаком `|`.
   - **courses.csv:**
     - `class`, `subject` — название предмета точно как в каталоге, например «Математика», «Естественные науки», «Mathematics: analysis and approaches»;
     - `teacher_email`;
     - `level` — `SL`/`HL` только для DP.
3. Сохраните: Excel — «Файл → Сохранить как → **CSV UTF-8**»; Google Таблицы — «Файл → Скачать → CSV».
   Файлы назовите `people.csv` и `courses.csv`.

**10.2. Отправить файлы на сервер.** На **своём компьютере** откройте второе окно PowerShell/Терминала (не на сервере!), перейдите в папку с файлами и выполните (вместо `IP` — адрес сервера):

```bash
ssh root@IP "mkdir -p ~/journal/data"
```

```bash
scp people.csv courses.csv root@IP:~/journal/data/
```

**10.3. Загрузить.** Вернитесь в окно сервера:

```bash
IMPORT="$C --profile tools run --rm -v $PWD/data:/data:ro tools node_modules/tsx/dist/cli.mjs scripts/import.ts"
```

Сначала проверка без сохранения:

```bash
$IMPORT people /data/people.csv --dry-run
```

Если написано `Проверка пройдена` — загружайте по-настоящему:

```bash
$IMPORT people /data/people.csv
```

```bash
$IMPORT courses /data/courses.csv
```

Если появилась `ОШИБКА`: ничего не сохранилось. В сообщении указана строка — исправьте её в таблице, отправьте файл заново (шаг 10.2) и повторите. Повторная загрузка не создаёт дублей.

## Шаг 11 (по желанию). Вход через Google

Чтобы учителя и ученики входили школьным Google-аккаунтом, а родители — своим Gmail:

1. Зайдите на **https://console.cloud.google.com** под аккаунтом администратора Google Workspace школы.
2. Вверху: «Select a project» → **New project** → название `Journal` → Create.
3. Меню ☰ → **APIs & Services** → **OAuth consent screen** (или «Google Auth Platform» → Branding):
   - App name: `Журнал IB`, support email — ваш;
   - Audience: **External**, если будут входить родители с Gmail; **Internal** — если только школьные аккаунты;
   - для External нажмите **Publish app**.
4. **Credentials** (или Clients) → **Create credentials** → **OAuth client ID**:
   - Application type: **Web application**;
   - Authorized redirect URIs → Add URI: `https://journal.ваш-лицей.kz/auth/google/callback`;
   - Create. Скопируйте **Client ID** и **Client secret**.
5. На сервере: `nano .env.production`, заполните:
   ```
   GOOGLE_CLIENT_ID=скопированный-id
   GOOGLE_CLIENT_SECRET=скопированный-secret
   GOOGLE_ALLOWED_DOMAINS=ваш-лицей.kz
   ```
   Сохраните (Ctrl+O, Enter, Ctrl+X) и перезапустите сайт:
   ```bash
   $C up -d app
   ```
6. На странице входа появится кнопка «Войти через Google». Email в Google должен совпадать с email в people.csv.

## Шаг 12. Выдать доступ людям

- **С Google** (шаг 11) людям ничего не нужно: они просто нажимают «Войти через Google».
- **По паролю, одному человеку:** в админке «Люди» → кнопка **«Доступ»** у человека → «Ссылка-приглашение» → «Копировать» → отправьте ему лично (WhatsApp, почта).
- **По паролю, всем родителям сразу:** на сервере выполните

  ```bash
  mkdir -p out && chown 65532 out
  ```

  ```bash
  $C --profile tools run --rm -v $PWD/out:/out tools node_modules/tsx/dist/cli.mjs scripts/invite-links.ts --role parent --out /out/links.csv
  ```

  Скачайте файл на свой компьютер (команда в окне **своего компьютера**):

  ```bash
  scp root@IP:~/journal/out/links.csv .
  ```

  В нём email и личная ссылка для каждого родителя (действуют 7 дней). Разошлите ссылки и **удалите файл** — и на компьютере, и на сервере:

  ```bash
  rm ~/journal/out/links.csv
  ```

## Шаг 13. Бэкапы — проверить и не забывать

Бэкап базы делается автоматически каждый день и хранится 14 дней в папке `~/journal/backups` на сервере. Посмотреть список:

```bash
ls -lh ~/journal/backups
```

Раз в неделю скачивайте свежий бэкап на школьный компьютер (окно **своего компьютера**):

```bash
scp "root@IP:~/journal/backups/*.dump" .
```

Если сервер сломается, без копии вне сервера данные будут потеряны. Восстановление описано в `docs/DEPLOY.md`, раздел 8.

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| Сайт не открывается | Проверьте DNS на https://dnschecker.org (шаг 2). На сервере выполните `$C ps`: все строки должны быть `Up`. |
| Ошибка сертификата HTTPS | Подождите 2–5 минут после запуска. Проверьте, что в `.env.production` в `DOMAIN` нет `https://` и лишних пробелов. |
| Хотите посмотреть журнал ошибок | `$C logs --tail 50 app` |
| Ссылка-приглашение «недействительна» | Она уже использована или истекла. Выдайте новую в «Люди» → «Доступ». |
| Человек забыл пароль | «Люди» → «Доступ» → «Ссылка для сброса пароля». |
| Пароль не подходит, «вход заблокирован» | Было 5 неверных попыток. Подождите 15 минут. |
| Уволился учитель | «Люди» → «Доступ» → «Заблокировать доступ»: он сразу выйдет со всех устройств. |

## Перед загрузкой реальных данных учеников

- Получите **согласия родителей** на обработку персональных данных детей.
- Назначьте **ответственного за персональные данные** (приказом).
- Заключите **договор с хостингом**: подтвердите, что сервер физически в РК.
- Подробно о мерах защиты — `docs/SECURITY.md`.
